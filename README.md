# Aplicație de Monitorizare a Calității Solului

> Proiect pentru disciplina Metode de Dezvoltare a Software-ului.

## Descriere

Sistem IoT pentru monitorizarea calității solului, format dintr-o aplicație software cu autentificare și cod pentru placa de dezvoltare care preia datele de la senzori.

## Conținut

- `Login/` — modulul de autentificare al aplicației
- `MonitorizareSol/` — aplicația principală de monitorizare
- `placuta_cod/` — codul pentru placa de dezvoltare (senzori)
- `resurse/` — resurse ale proiectului
- `BD.xlsx` — structura bazei de date
- `Document de Analiză și Proiectare pentru Aplicația Software.docx` — documentul de analiză și proiectare al proiectului
